### ✦ Hello, World! I'm Parth Kaushal 👋

> **Computer Science &amp; Engineering Student** exploring the intersection of **full-stack engineering**, **applied machine learning**, and **application security &amp; Web3**.

I am driven by a builder-first philosophy: taking complex systems apart to understand how they behave under real-world constraints. Whether that involves training predictive ML pipelines where feature quality beats parameter brute-force, tracing EVM bytecode execution, or building resilient web applications, I care about software that is robust, modular, and built from first principles.
